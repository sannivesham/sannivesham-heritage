## 🌟 Overview

**SANNIVESHAM** (*Explore • Experience • Preserve*) is a unified national digital cultural heritage platform. It connects sacred tangible monuments, classical performing arts, GI-tagged traditional handicrafts, living harvest festivals, classical languages, and oral memories into a unified, interactive platform.

---

## 🔥 5 Core Innovation Pillars

1. **🗺️ Cultural GIS (Interactive Geospatial Map)**:
   - Dynamic SVG map of India with clickable states and territories.
   - Layer toggles for: 🏛️ Heritage Sites, 🎭 Performing Arts, 🧵 Traditional Crafts, 🪔 Festivals, and 🗣️ Languages.
   - Rich state cultural dossiers with spotlight on **Telangana** (Charminar, Ramappa Temple UNESCO, Golconda acoustics, Pochampally Ikat, Oggu Katha, Bathukamma, Bonalu, Hyderabadi cuisine).

2. **🤖 Bharat AI Cultural Guide**:
   - Conversational AI cultural mentor providing source-grounded answers.
   - Grounded in official citations from the **Archaeological Survey of India (ASI)**, **National Archives of India**, and **IGNCA**.

3. **🎮 Culture Quest (Gamified Learning)**:
   - 5-Tier progression system (*Level 1: Know India* to *Level 5: Bharat Champion*).
   - Architectural challenges (Dravida vs Nagara vs Vesara), instant explanations, streak multipliers, and audio sound effects via Web Audio API.

4. **🎙️ Living Heritage Archive (Voices of Bharat)**:
   - Audio-narrated oral histories recorded from village elders, master weavers, and folk artists.
   - Dynamic audio waveform visualization, transcripts, and speaker profiles.

5. **🏛️ Heritage Preservation Network**:
   - **My Heritage**: Crowdsourced repository where citizens and students document family folklore and elder memories.
   - **Heritage Alert**: Civic preservation portal for reporting damaged monuments, neglected stepwells, and endangered crafts directly to authorities.

## 📱 Complete Screen Architecture (15 Screens)

| Screen | Name | Description |
|---|---|---|
| **01** | Landing Page | Cinematic India hero, royal palette, quick metrics, and Telangana spotlight |
| **02** | Cultural GIS Map | Interactive SVG India map with 5 filterable cultural dimensions |
| **03** | State Cultural Profile | Deep-dive cultural dossiers (Telangana, Rajasthan, Tamil Nadu, etc.) |
| **04** | Heritage Explorer | Multi-faceted catalog (State, Era, Category, Keyword) |
| **05** | Story of India | Scroll-based story of *Charminar* and *The Sun Temple at Konark* |
| **06** | Culture Quest | 5-Level gamified quiz with sound synthesis, XP, and badges |
| **07** | Bharat AI Guide | Conversational AI citing ASI and National Archives |
| **08** | Languages & Scripts | Multi-script comparison matrix with Web Speech API audio pronunciation |
| **09** | Festival Calendar | Month-by-month agricultural, seasonal, and ritual celebrations |
| **10** | Voices of Bharat | Living oral histories audio player with animated waveform |
| **11** | Community Heritage | Crowdsourced citizen archives with moderation workflow |
| **12** | Heritage Near Me | Hyperlocal geo-radius discovery (5 km, 15 km, 50 km) |
| **13** | Student Mode | Personalized 5-Day micro-curriculum generator |
| **14** | Leaderboard & Badges | Student and college rankings (SNIST, IIT Madras, etc.) with 3D badges |
| **15** | Virtual Tours | 360°/panoramic exploration of Hampi and Ramappa Temple with hotspots |
| **16** | Institution Mode | Teacher dashboard for grading and verifying student field reports |

## 🚀 Instant Local Run

Because BharatVerse is built using modern standard Web Standards and zero external npm bundle dependencies:

### Option 1: Double-click
Simply open [`index.html`](index.html) directly in any modern browser (Chrome, Edge, Firefox, Safari).

### Option 2: PowerShell Local Server
```powershell
powershell -ExecutionPolicy Bypass -File .\serve.ps1 -Port 8080
```
Then visit: `http://localhost:8080/`
